# Kaapi roadmap

## Current state

P0 is complete for Claude Code and is anchored by
`docs/KAAPI_BUILD_SPEC_v1.3.md`. The package checkpoint is `v1.0.0`; the P0
test suite passes with 96 tests.

## Planned next work

- **P1:** Codex support.
- **P1:** Custom organisational security-policy overlays.
- **P2:** Cursor, Gemini, and GitHub Copilot support.

The planned Kaapi roadmap ends at P2. A milestone update should add its source
material under `wiki/raw/`, update affected pages and this roadmap, append to
`wiki/log.md`, and record decisions in `Decisions.MD`.

## Explicitly out of scope

P0 does not include blast-radius analysis, OWASP mappings, SARIF, `explain`,
hosted services, or speculative adapter abstractions.
